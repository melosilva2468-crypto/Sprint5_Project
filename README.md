# Sprint 5 — Projeto de Análise de Veículos

## Descrição
Este projeto desenvolve um aplicativo web com Streamlit para explorar dados de anúncios de venda de veículos. O aplicativo permite visualizar os dados por meio de gráficos interativos.

## Funcionalidades
- Visualização dos dados de anúncios de veículos.
- Criação de um histograma.
- Criação de um gráfico de dispersão.
- Exploração interativa dos dados.

## Tecnologias utilizadas
- Python
- Pandas
- Plotly Express
- Streamlit
